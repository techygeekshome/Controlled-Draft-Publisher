Controlled Draft Publisher automatically publishes draft posts on a configurable interval instead of all at once — with per-post-type intervals, an optional publishing window (e.g. only 9am-6pm on weekdays), email alerts, an activity log, and an admin dashboard with start/stop, manual publish, and a "Next Up" preview showing exactly what's going out next.

Free, on WordPress.org, no bloat.

## ✨ What it does

- ⏱️ **Publish drafts at a configurable interval**, globally or per post type.
- 🕒 **Optional publishing window** and weekend skip, so drafts never go out overnight or on weekends unless you want them to.
- 📧 **Optional email alerts** when a draft is published or a publish attempt fails.
- ▶️ **Start/stop controls** and a manual "Publish Now" button.
- 👀 **"Next Up" preview** on the dashboard shows exactly which drafts will publish next, in order, before it happens.
- 🙅 **Per-post exclude option**, for the odd draft you want to hold back by hand.
- 📊 **Activity log** with timestamps, titles, and permalinks, exportable to CSV, plus a 7-day activity chart.
- 🎯 Works with selected post types and categories.
